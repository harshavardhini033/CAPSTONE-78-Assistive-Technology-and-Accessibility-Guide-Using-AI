Capstone 78 – Assistive Technology & Accessibility Guide Using AI

📌 Project Description

Capstone 78 is an AI-powered accessibility project designed to make digital educational content more inclusive and accessible for students with disabilities. The project explores how free Artificial Intelligence tools and assistive technologies can improve learning experiences through image descriptions, alternative text generation, text-to-speech, real-time captions, and document summarization.

The project evaluates AI tools such as ChatGPT, Google Gemini, ElevenLabs, Live Captions, and NotebookLM to support accessible educational materials.

It also introduces a Python-based automation workflow for generating alternative text prompts and provides practical guidelines for following WCAG 2.1 Level AA accessibility standards.

🎯 Objectives

- Improve digital learning accessibility for students with disabilities.
- Generate meaningful alternative text (Alt Text) for educational images.
- Support audio transcription and text-to-speech technologies.
- Evaluate free AI tools for accessibility applications.
- Follow WCAG 2.1 AA accessibility guidelines.
- Promote human verification of AI-generated content.

🛠️ Technologies Used

- Python

- ElevenLabs

- NotebookLM
- NVDA and VoiceOver
- WCAG 2.1 AA Guidelines

✨ Key Features

- AI-powered alternative text generation.
- Accessibility tool evaluation and accuracy analysis.
- Text-to-speech and real-time caption support.
- Python-based prompt automation.
- Inclusive learning checklist.
- AI hallucination verification and human review.

📂 Project Deliverables

- Research and Verification Report
- Project Presentation

🌍 Impact

This project aims to create an inclusive digital learning environment where every student can access educational content regardless of their abilities. It demonstrates how AI and assistive technologies can support accessible, effective, and responsible education.
